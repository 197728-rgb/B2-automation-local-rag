# Hard Lessons

Why the rules exist. One ID space: every lesson names the incident that taught it.

The rules themselves are in `../01_ACTIVE_RULES/`. This file does not restate them.

| Lesson | From |
|---|---|
| Identity precedes location. Meaning survives a revision; geometry does not. | AAR-R008 |
| A repeating row is a record, not a text bucket. Rows exist to keep identities separable. | AAR-R001, AAR-R002 |
| Absence is a conclusion, not an observation. "Not found" describes the search until every surface has been checked. | AAR-R014, AAR-R024 |
| Completeness runs both ways. Guarding only the target loses source facts; guarding only the source invents target values. | AAR-R003, AAR-R004, AAR-R010 |
| Blank is a governed state. Emptiness asserts that nothing was required, and that assertion needs authorization. | AAR-R020 |
| Visible and machine-readable are two results. A field can satisfy one and fail the other, and both are consumed downstream. | AAR-R005, AAR-R016 |
| Formatting belongs to the write. A later pass cannot tell an authorized change from controlled content. | AAR-R006 |
| Preservation beats regeneration when a baseline is accepted. Rebuilding re-runs every risk the accepted document already survived. | AAR-R007 |
| Suggestion and authorization are different powers. Ranking proposes; only something deterministic bounds consequences. | AAR-R011, AAR-R015 |
| Degradation must be loud. A silent fallback is indistinguishable from a confident answer. | AAR-R013 |
| Document status decides what completion means. Draft, final, and released are held to different requirements. | AAR-R009 |
| A checker finding is a claim, not a verdict. Requirement, field meaning, identity, and materiality decide. | AAR-R018 |
| A fix exists only on the path that ships. Verifying a helper proves the helper. | AAR-R021 |
| A fix without a test is on loan. Branch churn reliably deletes undefended changes. | AAR-R022 |
| Duplicate references are latent contradictions. They agree until one is edited, then the next reader picks by accident. | AAR-R023 |
| A claim is worth the check that can falsify it. Prose asserting a property, with nothing that fails when it is false, is intent presented as result. | AAR-R025 |
