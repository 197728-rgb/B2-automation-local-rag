# Failed Assumptions

Beliefs actually held in this work that proved false.

| Assumed | Actually | From |
|---|---|---|
| One fixed table map fits every activity code | Layout is a property of the form in hand | AAR-R008 |
| Every QAPE job audits the same elements | The audited set is assigned per package | AAR-R019 |
| Last year's row position identifies this year's field | Only semantic identity survives a revision | AAR-R008 |
| An empty extraction means no value exists | Controls, merge owners, and continuations all read empty naively | AAR-R014 |
| Blank is the safe default | A blank asserts non-applicability, which needs authorization | AAR-R020 |
| Two similar people or instruments can share a row | Similar is not the same | AAR-R001, AAR-R002 |
| A written procedure proves implementation | It can support a manual determination, not the act | AAR-R018 |
| A visible value in Word will extract | Content controls display what extracts as blank | AAR-R005 |
| A value in the XML is visible to the reader | It can sit inside a placeholder and render empty | AAR-R016 |
| Fixing the helper fixes the output | Only the shipping path decides | AAR-R021 |
| Starting from a blank is safest | An accepted completed form is the maintenance baseline | AAR-R007 |
| A regex tuned on clean text holds on OCR | Real OCR varies separators, spacing, and glyphs | AAR-R012 |
| A fix, once merged, stays merged | Reverts remove what no test defends | AAR-R022 |
| Two copies of a reference are harmless | They diverge the first time one is edited | AAR-R023 |
| The tool will find the files it was pointed at | Cloud placeholders and unsynced folders read as missing | AAR-R024 |
| A documented claim is a verified claim | Nothing verified it | AAR-R025 |
