# QAPE Rules

## 1. Only audited elements are evaluated

The audited set is assigned per package and is usually a subset. Read the current summary
marks; evaluate what is actually assigned. Leave non-audited elements alone.

Blocks AAR-R019.

## 2. Manual and Compliance are different questions

Documented-system evidence can support a manual determination. A compliance or
implementation determination needs evidence of the act itself. A procedure describes what
should happen; it does not show that it did.

Blocks AAR-R018.

## 3. Evidence families do not cross

B-2 technical demonstration evidence and QAPE program evidence are not interchangeable in
either direction. Each citation is labelled with the family it satisfies.

## 4. Document status decides what completion means

Draft, final, and released documents are held to different requirements. A draft-stage
signature blank is not a final-release defect.

Blocks AAR-R009. Enforced by `check_draft_status`.

## 5. A finding needs five things

Requirement · field meaning · entity identity · materiality · proof.

Missing proof is HOLD, never REJECT. A checker finding is a claim, not a verdict.
