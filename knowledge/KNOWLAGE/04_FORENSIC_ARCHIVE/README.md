# Forensic Archive

**HISTORICAL EXAMPLE — NOT CURRENT AUDIT AUTHORITY**

Detailed records of failures that actually occurred, kept for debugging and for
understanding why a rule exists. Nothing here authorizes a value, a field mapping, or a
finding in a live audit.

Any facility-specific value appearing in this layer is historical. Current facility values
come only from current audit evidence (AR-03). If a value here matches something in a live
job, that is coincidence and carries no weight.

Contents:

- `incidents/` — the incident records behind `../03_LESSONS/ERROR_LEDGER.md`
- `examples/` — concatenation and drift samples, kept as visual benchmarks only
